Rebuilding this site with an AI code editor

How I turned a free agency template into my own portfolio without typing code by hand.

  • Home
  • /
  • Journal
  • /
  • AI editor

The assignment sounded simple: take a free multi-page template and make it your own, but every change has to come from an AI tool. No typing code by hand. Here’s how it went.

Picking the template

I chose Orbitor by Themefisher, a free agency template built with Bulma, jQuery and plain CSS. It had nine pages, sliders and counters, which gave the AI plenty to work with.

What changed

  • A dark theme with a coral-to-peach gradient instead of the original white and orange.
  • New fonts: Sora for headings and Inter for text.
  • Every stock photo replaced with new SVG illustrations.
  • An animated “aurora” hero with typing text and a 3D-tilting code window.
  • Pricing merged into Services, the blog turned into this journal, and the project page now has filters and pop-ups.
  • A contact form that checks your input in the browser instead of needing a PHP server.
Describing the result I wanted worked much better than naming CSS properties.

What was hard

The AI sometimes fixed one page and forgot another, so after every big change I asked it to check all HTML files for broken links. Keeping a backup copy of the folder before each step saved me more than once.

What I learned

  1. Small, specific prompts beat one giant prompt.
  2. Always check the result at phone size.
  3. Reading the code the AI writes is the fastest way to learn it.
