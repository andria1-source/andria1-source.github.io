Weather Now

A five-day weather dashboard, my first app that talks to a real API.

  • Home
  • /

RoleDesign & development
Timeline2 weeks
ToolsHTML, CSS, JavaScript
TypeCourse project

The problem

Most weather sites are crowded with ads and pop-ups. I wanted a calm page that answers one question fast: “Do I need a jacket today?”

What I built

  • A search box that suggests cities as you type and remembers your last four searches.
  • A large “now” card plus a five-day forecast with simple bar charts.
  • A layout that changes from a row of cards on desktop to a scrolling list on phones.

What I learned

  1. How to read JSON from an API with fetch() and handle errors politely.
  2. How to keep small bits of state in localStorage.
  3. That designing the empty and error states first saves time later.
